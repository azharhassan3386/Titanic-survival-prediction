# Titanic Survival Prediction

## Overview
Exploratory Data Analysis and machine learning classification on the Titanic dataset to predict passenger survival.

## Key Analyses
- Missing value handling (Age, Embarked, Cabin)
- Survival trends by Gender, Class, Age, and Family Size
- Correlation heatmap
- Feature importance analysis

## Model Results
- Logistic Regression: 80.00% accuracy
- Random Forest: 82.68% accuracy

## Key Insight
Fare and Sex were the most important predictors of survival, followed by Age.

## Tools Used
Python, Pandas, Seaborn, Matplotlib, Scikit-learn, Jupyter Notebook
